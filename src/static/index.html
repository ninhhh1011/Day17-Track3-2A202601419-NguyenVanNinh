🏛️ Kiến Trúc 4 Tầng Bộ Nhớ (Multi-Layer Memory Architecture)

1. Short-Term / Working Memory

Lưu trữ cục bộ phiên làm việc hiện tại bằng kỹ thuật Sliding Window kết hợp Compaction. Nén các lượt hội thoại cũ thành state/TODO/constraints, giữ nguyên các deadline quan trọng (như REVIEW-DEADLINE-1600).

2. Long-Term / Declarative Memory

Managed trên Zep User Graph. Sử dụng Context Block tự động tổng hợp facts, preferences và giải quyết xung đột Recency (ưu tiên thông tin mới nhất khi user thay đổi stack công nghệ).

3. Episodic Memory

Tìm kiếm scope="episodes" trên User Graph để truy hồi lộ trình giải quyết vấn đề trong quá khứ (lỗi async timeout, bài học kinh nghiệm, provenance).

4. Semantic Memory

Standalone Knowledge Graph dùng chung cho mọi user. Lưu trữ tri thức domain (Payment API retry policy, Connection pooling guidelines) với literal markers bảo toàn nguyên vẹn.
